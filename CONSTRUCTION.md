# How to build the Erdős #106 counterexample from scratch

**Claim: `f(17) > 4`**, refuting the conjecture `f(k²+1) = k` at `k = 4`.

`f(n)` = the largest possible total of the side-lengths of `n` squares drawn inside a
unit square with pairwise disjoint interiors (they may touch; they need not be
axis-parallel).

This is not a list of 17 arbitrary numbers. The whole configuration is generated by
**two rationals** that solve a 2×2 linear system. Below is everything needed to rebuild
and check it independently.

---

## 1. The angle

Tilt exactly one square by the angle `t` with

```
cos t = 255/257        sin t = 32/257        q = cos t + sin t = 287/257
```

This is an **exact** rotation because `255² + 32² = 65025 + 1024 = 66049 = 257²`.
So `t ≈ 7.1527°`, and every coordinate below stays an exact rational — no floating point
is needed anywhere.

## 2. The two unknowns

Let

- `a` = combined width of the two left-hand columns,
- `u` = height of the middle band,
- and define `b = a − u`, `s = u / q`.

`a` and `u` are fixed by the two tangency conditions in §4. Both are **linear** in `(a, u)`:

```
a·(cos t + 4·sin t)        +  u·cos t·(3 − sin t/q)          =   cos t + (7/4)·sin t
a·(−2·sin t − 3·cos t)     +  u·(5·sin t + 2·cos t + cos²t/q) = −(3/4)·cos t
```

Solving with `cos t = 255/257`, `sin t = 32/257`:

```
a = 96363407/219038480     = 0.4399382565109108
u = 211886647/1095192400   = 0.1934697930701491
b = a − u = 67482597/273798100    = 0.2464684634407617
s = u / q = 189738217/1095192400  = 0.1732464697527119
```

## 3. The layout

Seven groups, seventeen squares. All are axis-parallel except the last.

| # | group | count | side | placement |
|---|-------|-------|------|-----------|
| 1 | left column | 4 | `1/4` | `x ∈ [0, 1/4]`, stacked from `y = 0` |
| 2 | second column | 3 | `a − 1/4` | `x ∈ [1/4, a]`, stacked from `y = 0` |
| 3 | bottom-right block | 4 | `(1−a)/2` | fills `x ∈ [a, 1]`, `y ∈ [0, 1−a]` (2×2) |
| 4 | top-left | 1 | `3/4 − 2b` | `x ∈ [1/4, 1−2b]`, `y ∈ [1/4+2b, 1]` |
| 5 | top-right | 2 | `b` | `y ∈ [1−b, 1]`, at `x ∈ [1−2b, 1−b]` and `[1−b, 1]` |
| 6 | middle band | 2 | `u` | `y ∈ [1−a, 1−b]`, at `x ∈ [1−2u, 1−u]` and `[1−u, 1]` |
| 7 | **the tilted one** | 1 | `s = u/q` | tilted by `t`, inscribed in the box `x ∈ [1−3u, 1−2u]`, `y ∈ [1−a, 1−b]` |

Group 7's bounding box is exactly `u × u`, since `s·q = u` by definition.

Its four corners, with `x₀ = 1−3u` and `y₀ = 1−a` (note `u − s·sin t = s·cos t`):

```
( x₀ + s·sin t ,  y₀            )
( x₀ + u       ,  y₀ + s·sin t  )
( x₀ + s·cos t ,  y₀ + u        )
( x₀           ,  y₀ + s·cos t  )
```

## 4. Why tilting wins — the two tangencies

Two squares intrude into the tilted square's box, and they are what make a straight
square lose:

- **group 2's top square** pokes up from the lower left; its top-right corner is `(a, 3a − 3/4)`
- **group 4's square** pokes down from the upper left; its bottom-right corner is `(1−2b, 1/4 + 2b)`

The two equations in §2 say precisely that the tilted square's two left-hand edges pass
**through those two corners**. That is what pins `a` and `u`.

Held straight, the largest square that fits in the same free space has side
`0.173122157348993`. Tilted, it reaches `0.173246469752719`. The gain,
`0.000124312`, is the entire margin — see §5.

## 5. The score

Adding all seventeen side-lengths collapses to

```
total = 4·(1/4) + 3·(a − 1/4) + 4·((1−a)/2) + (3/4 − 2b) + 2b + 2u + s
      = 3 + a + 2u + s
```

which evaluates to the exact rational

```
total = 2190452873/547596200 = 4.000124312403920968

total − 4 = 68073/547596200 = 1.2431240392e-4   > 0
```

**Sanity check that it is not absurd.** The area covered is `Σsᵢ² ≈ 0.96435 < 1`, as it must
be. Cauchy–Schwarz gives `Σsᵢ ≤ √(17 × 0.96435) ≈ 4.0489`, so `4.000124` sits below the
ceiling. And `Σsᵢ > 4` forces `Σsᵢ² > 16/17 ≈ 0.94118`, which `0.96435` satisfies.

**Where the margin comes from.** Replace the tilted square with the best *axis-parallel*
square that fits the same hole and the total becomes exactly `4` — the Baek–Koizumi–Ueoro
axis-parallel optimum. The whole counterexample is one tilt in one hole.

## 6. Rebuild and check it yourself

Standard library only, exact rationals, no floating point.

```python
from fractions import Fraction as F

COS, SIN = F(255,257), F(32,257); Q = COS + SIN
assert COS*COS + SIN*SIN == 1

# --- solve the 2x2 system for (a, u) --------------------------------------
A11, A12, B1 = COS + 4*SIN, COS*(3 - SIN/Q),               COS + F(7,4)*SIN
A21, A22, B2 = -2*SIN - 3*COS, 5*SIN + 2*COS + COS*COS/Q, -F(3,4)*COS
det = A11*A22 - A12*A21
a = (B1*A22 - A12*B2)/det
u = (A11*B2 - B1*A21)/det
b, s = a - u, u/Q

# --- build the 17 squares as (centre_x, centre_y, side, tilted) ------------
sq  = [(F(1,8), F(1,8)+F(k,4), F(1,4), False) for k in range(4)]
w   = a - F(1,4)
sq += [(F(1,4)+w/2, w/2 + k*w, w, False) for k in range(3)]
d   = (1-a)/2
sq += [(a + d/2 + i*d, d/2 + j*d, d, False) for i in range(2) for j in range(2)]
c   = F(3,4) - 2*b
sq += [(F(1,4)+c/2, 1-c/2, c, False),
       (1-2*b+b/2, 1-b/2, b, False), (1-b/2, 1-b/2, b, False),
       (1-2*u+u/2, 1-a+u/2, u, False), (1-u/2, 1-a+u/2, u, False),
       (1-F(5,2)*u, 1-a+u/2, s, True)]

# --- corners, exactly ------------------------------------------------------
def corners(cx, cy, side, tilted):
    h = side/2; out=[]
    for lx, ly in ((-h,-h),(h,-h),(h,h),(-h,h)):
        rx, ry = (COS*lx - SIN*ly, SIN*lx + COS*ly) if tilted else (lx, ly)
        out.append((cx+rx, cy+ry))
    return out

def area(p):
    if len(p) < 3: return F(0)
    return abs(sum(p[i][0]*p[(i+1)%len(p)][1] - p[(i+1)%len(p)][0]*p[i][1]
                   for i in range(len(p))))/2

def clip(poly, A, B):                    # keep the part left of A->B
    if not poly: return []
    ex, ey = B[0]-A[0], B[1]-A[1]
    f = lambda P: ex*(P[1]-A[1]) - ey*(P[0]-A[0])
    out = []
    for i in range(len(poly)):
        P, Qp = poly[i], poly[(i+1)%len(poly)]
        sp, sq_ = f(P), f(Qp)
        if sp >= 0: out.append(P)
        if (sp > 0 and sq_ < 0) or (sp < 0 and sq_ > 0):
            t = sp/(sp-sq_)
            out.append((P[0]+t*(Qp[0]-P[0]), P[1]+t*(Qp[1]-P[1])))
    return out

def overlap(P, R):
    poly = P
    for i in range(len(R)):
        poly = clip(poly, R[i], R[(i+1)%len(R)])
        if not poly: return F(0)
    return area(poly)

polys = [corners(*t) for t in sq]
outside = [i for i,P in enumerate(polys) for (x,y) in P if x<0 or x>1 or y<0 or y>1]
bad     = [(i,j) for i in range(17) for j in range(i+1,17)
           if overlap(polys[i], polys[j]) != 0]
total   = sum(t[2] for t in sq)

print("squares               :", len(sq))
print("corners outside       :", len(outside))
print("overlapping pairs     :", len(bad))
print("total side-length     :", total, "=", float(total))
print("total - 4             :", total-4, "=", float(total-4))
print("beats 4               :", total > 4)
```

Expected output:

```
squares               : 17
corners outside       : 0
overlapping pairs     : 0
total side-length     : 2190452873/547596200 = 4.000124312403921
total - 4             : 68073/547596200 = 0.00012431240392099142
beats 4               : True
```

Before trusting the checker, confirm it behaves: it should accept a 4×4 grid of side-1/4
squares (total exactly 4), accept two squares touching edge-to-edge (the problem forbids
only common **interior** points), and reject two genuinely overlapping squares — including
a tilted one.

### 6b. Verification with no geometry routine at all

A fair objection to any tight packing is that some *particular* clipping routine might miss
a microscopic overlap. That objection can be removed entirely: for each of the 136 pairs we
exhibit an explicit **separating axis** and an exact rational gap. Checking one witness needs
no algorithm — four multiplications and a comparison:

> for a unit direction `d`, if `|(c_j − c_i)·d| ≥ E_i + E_j`, where `E` is each square's
> projected half-width onto `d`, then the projections do not overlap in their interiors, so
> the squares share no interior point.

Running `witness.py` over the closed-form configuration gives:

```
pairs examined          : 136
strictly separated      : 100
touching (gap exactly 0):  36     <- legal; only interiors must be disjoint
OVERLAPPING (gap < 0)   :   0
smallest gap            : 0       (exact rational, not 1e-17)

containment: 0 walls violated, smallest clearance exactly 0
```

The point is the word **exactly**. In rational arithmetic there is no "microscopically
overlapping" state: a gap is a rational number that is either negative or it is not. The
minimum over all 136 pairs is the exact integer `0`, so every contact in this configuration
is a true tangency, and no pair overlaps by any amount however small.

## 7. What this does and does not contradict

- It does **not** contradict Baek–Koizumi–Ueoro (2024), who proved `g(k²+2c+1) = k + c/k`
  only for **axis-parallel** squares. Our square #17 is tilted.
- It does **not** contradict `f(16) = 4`, which is a Cauchy–Schwarz theorem valid for tilted
  squares too.
- It is consistent with `f(10) = 3`: the 3×3 grid is a perfect tiling with no gaps, so there
  is nothing for a tilt to exploit.

### Exact scope — please state this carefully

`k(f(k²+1) − k)` is non-decreasing in `k` (Anshul Raj Singh). So `f(17) > 4` gives

```
f(k²+1) − k  ≥  4·(68073/547596200)/k  =  (68073/136899050)/k  ≈  4.9725e-4 / k     for every k ≥ 4
```

That refutes `f(k²+1) = k` **as a general statement**, and with it the whole
Erdős–Soifer / Campbell–Staton family `f(k²+2c+1) = k + c/k` (via Praton's equivalence).

It does **not** mean the conjecture fails at every `k`. It cannot:

| k | case | status |
|---|------|--------|
| 1 | `f(2) = 1` | **proven true** (Erdős) |
| 2 | `f(5) = 2` | **proven true** (Newman) |
| 3 | `f(10) = 3` | open; our search found nothing, consistent with it being true |
| ≥ 4 | `f(k²+1) > k` | follows from this counterexample |

So the correct phrasing is "it kills the conjecture, and specifically fails for every
`k ≥ 4`" — not "it fails for all `k`".
